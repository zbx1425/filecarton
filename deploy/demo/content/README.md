## 📦 FileCarton Demo

**FileCarton** is a lightweight PHP web file manager, designed for self-hosting and integration into other applications.  

We prepared some files for you to try it out!

| Folder | What are inside |
| --- | --- |
| Root | Selected files and a few archive files. Note that FileCarton supports previewing the contents of archives. |
| `Photos` | Thumbnails and the lightbox. Paintings and NASA photographs are in this one folder. `Various Formats` is the same Earthrise frame as JPEG, PNG, WebP, BMP, GIF, and ICO, plus SVG drawings and short animations. |
| `Music` | Play the Armstrong recording, then the same line as FLAC, MP3, Ogg, M4A, and AAC. Two Kevin MacLeod pieces are here too. |
| `Video` | Apollo 11 on the ladder (WebM and MP4), a Saturn V clip, a five-second flower, and the Sintel trailer. |
| `Reading` | A PDF, plain text, an EPUB, and Markdown, including a few public-domain poems. |
| `Workshop` | `lumen-field-kit` is the deep folder. The furthest file is `src/app/components/charts/SkyChart.tsx`. `data-files` holds CSV, TSV, JSON, GeoJSON, and SQLite. Open `Countries.json` or `Cities.json` in the editor. The `.geo.json` files are one long line each. Fonts and `Lantern.glb` have no preview. |
