# How the field kit is organized

The interesting files are under `src/`. Build files sit next to this folder's parent `README.md`.

A long filename is part of the test: the breadcrumb and the row should truncate, and the full name should still be there when you hover or rename.

Try opening this file, switching between preview and edit, and following a link that is only text. Relative images are not rewritten by the previewer, so pictures live as their own files.
