# Lumen Field Kit

A tiny, original star-catalog notebook. Nothing here is a real library. Each file exists so the editor has a different language to highlight, and so the folder tree, breadcrumbs, and filename search have somewhere to go.

Open a file, then use the editor status bar to change wrapping, indent, and the detected language.

```sql
select name, magnitude
from stars
where magnitude < 1
order by magnitude;
```
